Flower Shop Network is a platform that connects customers with local florists across the country. They provide an online marketplace where users can browse and purchase a wide variety of floral arrangements for all occasions, and expose a JSON API for partner POS systems to authenticate, look up products and florists, and exchange wire orders across the FSN florist network.

**APIs.json:** [https://raw.githubusercontent.com/api-evangelist/flower-shop-network/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/flower-shop-network/refs/heads/main/apis.yml)

## APIs

### Flower Shop Network JSON API

The FSN JSON API is a REST-style HTTPS interface for florist POS systems and partners to authenticate, retrieve product data, search filling florists, and send, receive, accept, refuse, and confirm wire orders.

- **Human URL:** [https://api.flowershopnetwork.com/](https://api.flowershopnetwork.com/)
- **Base URL:** `https://api.flowershopnetwork.com/api/`
